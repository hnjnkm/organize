# organize

기존 Pinterest 디자인 리서치 라이브러리의 2026-11-05 스냅샷에서 추출한 개발 버전입니다. 화면 구조, CSS 선언 순서, 한영 사전, 검색/필터/모달/영상 로직을 유지했습니다. 원본 보드: https://kr.pinterest.com/hnjnkm_/research-gui/

## 실행

Node.js 24 이상과 Chrome을 사용합니다. 외부 npm 의존성이나 빌드 단계는 없습니다.

```sh
npm run import -- "/path/to/organize-current-snapshot.html"
npm start
```

현재 클라우드 작업 환경에는 자료를 이미 가져왔으므로 `npm start`만 실행합니다. Chrome에서 `http://127.0.0.1:4318`을 엽니다. Windows에서는 `START.cmd`도 사용할 수 있습니다. 서버는 루프백에만 바인딩합니다. 다른 포트는 `PORT` 환경변수로 지정합니다.

## 파일과 데이터 보존

- `public/index.html`: 기존 화면 구조
- `public/styles.css`: 기존 스타일과 내장 Pretendard 폰트·라이선스
- `public/app.js`: 기존 UI, 분류, 편집, 내장 데이터 대신 JSON 로딩
- `public/menus.js`: 기존 커스텀 선택 메뉴
- `server.cjs`: 개발용 정적 파일 서버 (기존 수집 서버를 복원한 것은 아닙니다)
- `data/snapshot.json`: 71개 핀, 이미지와 24개 영상 및 분류 메타데이터. Git에서 제외합니다.

Git에는 코드만 저장합니다. 다른 컴퓨터에서는 원본 HTML 또는 `data/snapshot.json`을 별도로 복사해야 합니다. 가져오기는 기존 파일을 덮어쓰지 않습니다. 새 자료로 교체하기 전 기존 데이터와 화면의 JSON 백업을 별도로 보관하세요. 원본 HTML은 변경하지 않고 별도로 보존하세요.

편집은 원본처럼 해당 브라우저/주소의 localStorage(`form-snapshot-edits`)에 저장됩니다. 브라우저나 포트가 바뀌면 편집 내용이 자동 이동하지 않습니다. JSON 백업 버튼은 편집한 자료와 내장 미디어를 내보냅니다. JSON 백업 복원 UI는 아직 없습니다. 중요한 변경 후 백업을 보관하세요.

## 현재 범위

스냅샷에 실제 들어 있던 기능을 이어받았습니다. Pinterest 자동 동기화, Chrome 로그인, 서버의 보관본 ZIP 생성은 이 파일에 포함되지 않았으며 복원되지 않았습니다. 원래 스냅샷의 관련 안내/버튼 동작을 유지합니다. 보드 주소만으로 이전 서버·로그인 세션·브라우저 편집을 복원할 수 없습니다. 현재 구조는 1만 개 자료를 위한 최적화를 구현한 상태가 아닙니다.

## 검증

`npm test`로 자료 구조 및 개발 서버의 응답·접근 제한을 확인합니다. 자료 파일이 없으면 자료 검증은 건너뜁니다. UI 수정 시 Chrome에서 카드 이미지, 영상, 검색, 언어 전환, 모달 저장 및 모바일 레이아웃을 확인하세요.
